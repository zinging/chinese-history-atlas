# 教学法（Pedagogy）

三条设计原则在内容层与教学编排层的落法。所有 Agent 提示词、前端文案都以本文为准。

## 1. 非应试导向

- 不设标准答案。测验生成的必须是开放题："你觉得为什么""如果是你会怎么做"。
- 每个历史节点自带 ≥1 个开放问题（`controversies` 或 `timeline` 后的"想一想"）。
- 孩子答什么都能往下走，答"不知道"也是有效回答——继续引导讨论，不判错。

## 2. 图文并茂

- 每个历史节点绑定视觉元素：时间线（`timeline` 升序数组）、地图（`places` 经纬度热区）、人物卡片（`people` 头像位）。
- AI 插图只做辅助，不替代史实图（明代绘画、文物照片）。插图必须标注"AI 生成，仅供示意"。
- 可视化 Agent 只输出渲染所需 JSON，不直接画图；画图属于儿童交互层。

## 3. 孩子当导演

- 选择题要让孩子"选剧情"，不是选答案：例如"如果你是建文帝，靖难时你会怎么守南京"。
- 决策游戏的分支由孩子自己的选择触发，AI 只提供每个分支的后果与开放问题。
- 孩子的选择、提问、判断都要被记录（家长报告 Agent 消费），作为后续内容的个性化输入。
