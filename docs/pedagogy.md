# 教学法（Pedagogy）

三条设计原则在内容层与交互层的落法。所有前端文案、AI 提示词都以本文为准。

## 1. 非应试导向

- 不设标准答案。问典题目必须是开放题："你觉得为什么""如果是你会怎么做"。
- 每个历史节点自带 ≥1 个开放问题（`controversies` 或 `timeline` 后的"想一想"）。
- 答"不知道"也是有效回答——继续引导讨论，不判错。
- 帝王谱系的 77 道史论选择题虽然会批改对错，但题型限定为「论证判断」（如何评价这项政策）与「因果链」（此事因何发生），考的是推理路径，不是年代记忆。
- 探案问史的侦探案卷没有标准答案，只给出带出处的线索，判断权交给读者。

## 2. 图文并茂

- 每个历史节点绑定视觉元素：时间线（`timeline` 数组）、地图（`places` 经纬度热区）、人物卡片（`people` 像）。
- AI 插图只做辅助，不替代史实图。插图必须标注"工笔淡彩风格示意"，不作为史料图像引用。
- 可视化与数据分离：`buildMapData()` 只算数据，`renderMap()` 只管画，数据层可脱离地图库测试。

## 3. 读者当导演

- 选择题要让读者"选剧情"，不是选答案：例如"如果你是建文帝，靖难时你会怎么守南京"。
- 每个开放问题至少给出两个视角，不预设结论。
- 判断、提问、追问的入口在「探案问史」与「问典」两处，AI 老师只提供背景与线索，不代下结论。

## 三条原则的落地位置

| 原则 | 内容层字段 | 交互层入口 |
|---|---|---|
| 非应试 | `controversies`、`discourses`（问典） | 探案问史 · 问典 · 开放案卷 |
| 图文 | `timeline`、`places`、`people`、`portrait` | 帝王世系 · 舆图疆域 · 器物图谱 · 神话舆图 |
| 读者主导 | `open`、`viewpoints` | 侦探案卷 · AI 老师追问框 |

## AI 讲解员的教学边界

MCP Server 与网页内 AI 老师共用一套系统提示词（`web/serve.mjs` 的 `SYSTEM_PROMPT`）：

- 史实优先：只讲有史料依据的内容，拿不准就说"没有确切记载"，绝不编造人名、地名、年份。
- 演义分开：传说、演义明确标注，不与正史混淆。
- 短句口语：专有名词第一次出现时括号解释。
- 不判错：先肯定思考的部分，再温和补充史实。
- 不替读者下结论：开放问题只给线索与多视角，判断权留给读者。
