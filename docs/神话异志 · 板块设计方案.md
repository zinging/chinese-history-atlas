## 二、板块定位（和现有四板块的关系）

```
帝王谱系  → 正史：人做了什么
思想源流  → 哲思：人想了什么
诗词鉴赏  → 抒情：人感受什么
格物致知  → 科技：人造了什么
神话异志  → 想象：人梦见了什么  ← 新增
```

定位不是"迷信"或"故事书"，而是**中国古代世界观的博物馆**——古人怎么想象天地、山川、幽冥、神仙，怎么用神话解释未知。这和你项目"给孩子看"的调性完全契合。

## 四、四大子页设计（复用现有框架，但内容换骨架）

### 1. 典籍长廊（默认页）

- 五部书的卡片，和格物致知同款

- 每张卡片：书名封面工笔图 + 一句定位（如"上古山海经，写满了中国人最早的想象力"）

- 点开后：这本书的"结构"——不是时间线，而是

  分类索引

  - 山海经：按"山经/海经/大荒经"分卷，每卷列出异兽
  - 西游记：按"取经阶段"分（出山→两界山→火焰山→灵山）
  - 封神：按"阵营"分（周营/商营/阐教/截教）

### 2. 神兽图鉴（核心亮点，替代"公案疑案"）

- 这是本板块最有记忆点的页面
- 网格布局展示所有异兽/仙人/鬼怪，每张工笔淡彩图
- 点击弹出：出处（哪部书哪一卷）、外形特征、能力、相关故事
- 筛选维度：
  - 按书（山海经/西游/封神...）
  - 按类别：神兽 / 仙人 / 鬼怪 / 异人 / 法宝
  - 按属性：龙属 / 凤属 / 九尾属 / 人首兽身...
- **数据来源**：你已有的 artifacts 图直接用，缺的补生成

### 3. 神话舆图（地图页）

- 这是最能体现"中国古代世界观"的页面
- **山海经地图**：以五藏山经为骨架，标出每座山的位置、山神、异兽
- **西游取经路线图**：从长安→两界山→火焰山→流沙河→灵山，每个节点标故事
- **封神战场图**：孟津、渭水、封神台位置
- 用你已有的 Leaflet 框架，图层切换"山海经/西游/封神"三套数据

### 4. 探问异闻（答题/思辨）

- 不做普通选择题，做"神话侦探"式：
  - "精卫填海为什么是一只鸟？"（出处+象征意义）
  - "孙悟空的师父菩提祖师到底是谁？"（学界有争议）
  - "聊斋里的狐仙为什么大多比人好？"（蒲松龄的议论）
- AI 史老师换成"说书人"人设，讲神话不吓人但有文化味

## 五、独有交互设计（和其他板块的差异点）

| 交互               | 说明                                              |
| ------------------ | ------------------------------------------------- |
| **神兽图鉴翻牌**   | 默认剪影，点开才看到工笔图+名字，有"猜异兽"的趣味 |
| **取经路线时间轴** | 横向滑动，每站一个劫难卡片，点开放大看妖怪档案    |
| **封神榜树状图**   | 周营/商营两大阵营，点击人物看神位                 |
| **聊斋"夜读"模式** | 冷月色调，故事分段展开，像深夜翻书                |
| **山海经异国志**   | 十个奇异国度（君子国、大人国、女儿国...），卡片式 |

## 七、实施优先级建议

**第一期（先做一个能打的最小版）**：

1. 只做**山海经**一部书——它素材最多、异兽图鉴最直观、已有图最多
2. 子页只开"典籍长廊"和"神兽图鉴"两个
3. 地图和探问第二期再加

这样你能在一个迭代里看到完整效果，再决定要不要扩到西游/封神。

**第二期**：加西游记（取经路线图是天然亮点） **第三期**：加封神 + 聊斋

------

## 八、和现有项目的一致性

- 技术栈完全复用：原生 HTML/CSS/JS、iframe 懒加载、Leaflet 按需加载
- 视觉语言一致：宣纸底纹、工笔淡彩图、朱砂红主色
- 数据结构照搬格物致知的"按书拆分 JSON + 按需 fetch"模式
- 不需要新建任何后端或构建工具

**结论：值得做，素材完全够，而且能补全你项目"正史—哲思—抒情—工艺—想象"的完整光谱。** 建议从山海经单书起步，跑通后再扩展。
