## 二、板块定位（和现有四板块的关系）



```
帝王谱系  → 正史：人做了什么
思想源流  → 哲思：人想了什么
诗词鉴赏  → 抒情：人感受什么
格物致知  → 科技：人造了什么
神话异志  → 想象：人梦见了什么  ← 新增
```

定位不是 "迷信" 或 "故事书"，而是**中国古代世界观的博物馆**—— 古人怎么想象天地、山川、幽冥、神仙，怎么用神话解释未知。这和你项目 "给孩子看" 的调性完全契合。

## 四、四大子页设计（复用现有框架，但内容换骨架）

### 1. 典籍长廊（默认页）



* 五部书的卡片，和格物致知同款

* 每张卡片：书名封面工笔图 + 一句定位（如 "上古山海经，写满了中国人最早的想象力"）

* 点开后：这本书的 "结构"—— 不是时间线，而是

  分类索引


  * 山海经：按 "山经 / 海经 / 大荒经" 分卷，每卷列出异兽

  * 西游记：按 "取经阶段" 分（出山→两界山→火焰山→灵山）

  * 封神：按 "阵营" 分（周营 / 商营 / 阐教 / 截教）

### 2. 神兽图鉴（核心亮点，替代 "公案疑案"）



* 这是本板块最有记忆点的页面

* 网格布局展示所有异兽 / 仙人 / 鬼怪，每张工笔淡彩图

* 点击弹出：出处（哪部书哪一卷）、外形特征、能力、相关故事

* 筛选维度：


  * 按书（山海经 / 西游 / 封神...）

  * 按类别：神兽 / 仙人 / 鬼怪 / 异人 / 法宝

  * 按属性：龙属 / 凤属 / 九尾属 / 人首兽身...

* **数据来源**：你已有的 artifacts 图直接用，缺的补生成

### 3. 神话舆图（地图页）



* 这是最能体现 "中国古代世界观" 的页面

* **山海经地图**：以五藏山经为骨架，标出每座山的位置、山神、异兽

* **西游取经路线图**：从长安→两界山→火焰山→流沙河→灵山，每个节点标故事

* **封神战场图**：孟津、渭水、封神台位置

* 用你已有的 Leaflet 框架，图层切换 "山海经 / 西游 / 封神" 三套数据

### 4. 探问异闻（答题 / 思辨）



* 不做普通选择题，做 "神话侦探" 式：


  * "精卫填海为什么是一只鸟？"（出处 + 象征意义）

  * "孙悟空的师父菩提祖师到底是谁？"（学界有争议）

  * "聊斋里的狐仙为什么大多比人好？"（蒲松龄的议论）

* AI 史老师换成 "说书人" 人设，讲神话不吓人但有文化味

# 聊斋志异 & 太平广记 · 神话舆图扩展方案（设计稿，不动代码）

## 一、先判断"空间性格"——两本书和已有三条路线根本不同



| **已有板块** | **空间本质**       | **地图形态**   |
| -------- | -------------- | ---------- |
| 山海经·想象世界 | 并列神异空间（无主角轨迹）  | 分布图（不连线）   |
| 西游记·取经之路 | 线性旅程（17站一站一站走） | 路线图（连线+箭头） |
| 封神·战场    | 战役推进（伐纣一路打过去）  | 路线图（连线+箭头） |

**聊斋志异（491篇）和太平广记（500卷）都没有"主角按顺序走完一条路"这回事**——它们是故事集，硬套西游/封神那种连线路线图会变成伪路线，反而违背你一直要求的"严格按原著"。

所以推荐**不做路线图，做"分布/时空图"**，外壳继续复用现在的"古图 + 红色热点 + 人物卡片"交互，但点位语义和底图重新设计。



***

## 二、聊斋志异 → 推荐形态：「聊斋夜世界」场景分布图

**核心立意**：聊斋的真神是"夜晚"——荒寺、古宅、山岗、水滨，鬼狐在灯下出没。不按真实城市画，画一张**工笔夜色长卷**：淄川郊外夜景（城郭一角 + 山岗 + 荒寺 + 古宅 + 水滨），热点落在"典型故事场景"上。

**点位（8–10个，全选代表作，不凑数）**：



| **热点** | **场景** | **原著锚点**            | **卡片人物**  |
| ------ | ------ | ------------------- | --------- |
| 兰若寺    | 古寺荒阶   | 「寺僧不耐，见意侠。宁坦然受之」    | 宁采臣、聂小倩   |
| 太原王宅   | 书斋描皮   | 「铺人皮于榻，执彩笔绘之」       | 王生、画皮鬼、道士 |
| 莒州山岗   | 捻梅花少女  | 「携一枝梅花，容华绝代，笑容可掬」   | 王子服、婴宁    |
| 华阴蟋蟀笼  | 促织     | 「宣德间，宫中尚促织之戏……逐而得之」 | 成名、小促织    |
| 崂山     | 穿墙术    | 「壁灰质，似有门状……愕然而醒」    | 崂山道士、王生   |
| 陵阳地府   | 陆判换心   | 「审判之厅，神貌殊异」         | 朱尔旦、陆判    |
| 丰都枉死城  | 席方平告状  | 「冥王命以火床，血肉糜烂」       | 席方平       |
| 郑女水滨   | 连城     | 「闽人，姓史，绅家女」         | 史连城、乔大年   |

**视觉锤**：一张工笔夜色长卷（墨蓝/青灰主色，灯笼黄光点点），热点是暗红圆点，点开浮卡 = 场景工笔图 + 原著摘录 + 人物小像。

**关键差异**：



* ❌ 不画连线（故事之间没有行走关系）

* ❌ 不画方向箭头

* ✅ 卡片右上角加"蒲松龄原稿"字样，强化"笔记"感

## 三、太平广记 → 推荐形态：「唐前奇闻时空图」

**核心立意**：太平广记跨汉魏到宋初600年，它的真神是**朝代层叠**——不是"一个时代的一条路"，而是"同一方山河上，不同朝代先后发生的奇闻"。底图用工笔唐代山河（长安-洛阳-江南-浙江），每个热点加一枚**朝代小签**（汉/魏晋/唐），故事在地图上是"叠加"而非"串联"。

**点位（8–10个，现有3篇扩到名篇矩阵）**：



| **朝代签** | **热点** | **故事** | **原著锚点**             |
| ------- | ------ | ------ | -------------------- |
| 汉       | 天台山    | 刘阮天台   | 「入天台山采药，迷不得返……食以胡麻饭」 |
| 唐       | 长安平康坊  | 李娃传    | 「长安之狎游者，遇娃于平康里」      |
| 唐       | 邯郸客店   | 枕中记    | 「黍未熟，而一生已过」          |
| 唐       | 蒲州普救寺  | 莺莺传    | 「唐贞元中，张生游于蒲」         |
| 唐       | 长安升道里  | 任氏传    | 「唐天宝九年，郑子偕季弟游长安西市」   |
| 唐       | 广陵东槐里  | 南柯太守传  | 「淳于棼醉卧其堂之东庑……槐安国」    |
| 唐       | 洞庭湖君山  | 柳毅传    | 「仪风中，有儒生柳毅者，应举下第」    |
| 唐       | 马嵬驿    | 长恨歌传   | 「玄宗幸蜀，次马嵬」           |

**视觉锤**：一张工笔唐代山河图，热点带朝代小签（汉=青、唐=赭红），卡片里同时出现"朝代 + 卷次出处（如《太平广记·卷四百九十一》）"。

**关键差异**：



* ❌ 不画连线

* ✅ 热点左上角小朝代标签（汉/唐）

* ✅ 卡片加"《太平广记·卷X》"出处行，强化类书属性

## 四、为什么不直接照搬"路线图"——三个技术判断



1. **聊斋没有主角轨迹**。491篇是蒲松龄书房里攒出来的，事件之间没有时间先后，连线 = 伪造叙事。

2. **太平跨600年**。汉代的刘阮和唐代的李娃在地图上连线，等于告诉用户他们在同一时间行走，这是史实错误。

3. **但"古图 + 红色热点 + 浮卡"这个视觉锤必须保留**——这是你整个神话舆图的辨识度，不能因为不做路线就退化成纯文字列表。
