# data/portraits · 皇帝画像（AI 生成 / 馆藏图）

每个皇帝一个画像文件，前端渲染规格如下。

> 十六帝外貌考证与完整提示词见 **[prompts.md](prompts.md)**（外部 LLM 核验：仅太祖、成祖有《明史》本纪外貌原文；南薰殿御像缺建文、崇祯，景泰为清人补绘）。

## 格式要求

| 项 | 要求 |
|---|---|
| 文件命名 | 与皇帝条目 `portrait` 字段一致，如 `yongle.jpg` |
| 格式 | JPG 或 PNG（浏览器通用） |
| 尺寸 | **方形（1:1）**，建议 ≥512×512（卡片 84px、详情 110px，圆形裁剪，`object-fit: cover`） |
| 内容 | 正面/半侧头像为主，头部居中，避免全身或大场景（圆框会裁掉） |
| 风格 | 儿童向 Q 版 / 插画风 / 馆藏画像均可；AI 生成需在页面注明"AI 生成，仅供示意" |

## 前端如何接

- 皇帝条目 `portrait` 字段填文件名（如 `yongle.jpg`），前端从 `../data/portraits/<文件名>` 加载。
- 字段为空 → 回退 emoji 占位（当前首页 16 帝都还没图，全靠 emoji，等你放图）。
