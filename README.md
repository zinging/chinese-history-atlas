# 🏮 历史大冒险・中国历史可视化学习网站

> **语言 / Language：** 中文 | [English](README_EN.md)

一个以皇帝为线索、把 **隋・唐・五代・宋・元・明・清** 七个朝代串成可视化时间线的历史学习网站。它不要求死记年代，而是让你顺着卡片、地图、案件和解谜任务，自己把「谁在什么时候、做了什么、为什么、留下什么后果」连成一条线——适合学生入门，也适合想把中国历史重新理一遍的成年人。

## ✨ 项目亮点

* **一条线看懂一个朝代**：横向皇帝卡片流，点开即见该帝的生平时间线、人物关系、冷知识与争议话题，朝代更替不再是孤立的年号表。
* **历史落地在地图上**：Leaflet 可缩放底图叠各朝疆域轮廓与古地名点，行军、航海路线（靖难南下、郑和七下西洋、清军入关等）按时间分段动画呈现。
* **案件式深度阅读**：著名疑案（靖难之役、蓝玉案、乌台诗案、土木堡之变、崖山海战……）拆成「名称由来—背景—人物—经过—结果—影响—开放讨论—史料出处」八段。
* **线索可溯源**：时间线与侦探线索均标注《旧唐书》《宋史》《明史》等出处，演义与正史分开标注。
* **零依赖、可自托管**：纯原生 HTML/CSS/JS，无构建、无框架、无后端；`data/` 全是可读 JSON，可直接二次加工或喂给自己的知识库。
* **可接 AI 私教**：内置 OpenAI 兼容接口，可接 DeepSeek / OpenAI 等，陪读、答疑、点评你的回答，配置只存本机。

## 🧭 可以怎么学

| 学习方向 | 你可以做什么 |
| --- | --- |
| **建立朝代框架** | 从时间线页通读七朝皇帝顺序，先有「唐之后是五代、再是宋」的大坐标 |
| **理解关键人物** | 点进任一皇帝，看他的人物关系图（君臣、后妃、对手）和生平时间线 |
| **看懂重大事件** | 在地图上按年号筛选，看一场战役/政变从哪里开始、打到哪里、结果如何 |
| **辨析历史争议** | 读案件卡与「思辨一下」开放问题，比如「柴荣不死能否收复燕云」「崇祯勤政为何亡国」 |
| **训练史料思维** | 用历史侦探：先给你带出处的线索，再让你自己下判断，而不是直接给结论 |
| **古今地名对照** | 地图上每个古地名都可点，标注今天对应哪里（如「睦州」= 今浙江建德一带） |

## 🚀 快速开始



```bash
# 1. 克隆后进入项目根目录
cd dsh_his

# 2. 启动本地静态服务器（默认端口 5173）
node web/serve.mjs

# 3. 浏览器打开
#    http://127.0.0.1:5173/web/
```

> 环境要求：Node.js 18+（自带 `fetch`，无需 `npm install`）。端口被占用时换一个：`node web/serve.mjs 8080`，再访问 `http://127.0.0.1:8080/web/`。

**为什么必须起本地服务器，不能直接双击 HTML？** 前端通过 `fetch` 读取 `../data/` 下的 JSON，直接用 `file://` 打开会被浏览器的 CORS 策略拦截，页面会空白。

**可选 · 接入 AI 老师**：进入「历史侦探」页 → 拉到底部「🤖 AI老师配置」→ 填入任意 OpenAI 兼容接口地址（DeepSeek、硅基流动、OpenAI 等）+ API Key + 模型（可点 ⬇ 自动拉取、再从下拉选择）→ 保存后即可提问或让它点评你的回答。配置只存在本机 `web/llm-config.json`，**已在 .gitignore 中，不会被提交**。仓库里附带了带注释的 `web/llm-config.json.template`，可复制为 `llm-config.json` 后按说明填写。

## 🏗️ 架构



```
项目根
├── data/            # 知识层：七朝内容数据
│   ├── emperors/    #   明朝 16 帝（各一文件）+ index.json
│   ├── events/      #   明朝事件 + 地图事件点位
│   ├── cases/       #   明朝案件卡
│   ├── places/      #   古今地名对照
│   ├── routes/      #   明朝行军/航海路线
│   ├── boundaries/  #   各朝疆域 GeoJSON（明/唐/元/清）
│   ├── song/ tang/ yuan/ qing/ sui/ wudai/
│   │                #   各朝独立目录（events/people/cases/emperors/routes/map-events）
│   ├── schema/      #   各库 JSON Schema
│   ├── sources/     #   史料书目
│   └── portraits/   #   皇帝/人物画像（224 张，已压缩至 10MB）
├── web/             # 前端交互层：纯原生 HTML/CSS/JS
│   ├── index.html   #   四页骨架
│   ├── app.js       #   数据加载 + 渲染 + 交互（含 __mingTest 测试钩子）
│   ├── search-core.js # 检索核心（与插件 ming_search 同规则）
│   ├── serve.mjs    #   本地静态服务器 + LLM 代理 API
│   ├── vendor/      #   Leaflet 1.9.4（本地化，无 CDN 依赖）
│   └── tools/       #   数据脚本（画像压缩、补路线、补地名等）
├── plugin-final/    # DSH 插件（可选）：对话式历史问答，共享同一份 data/
├── scripts/         # 数据维护脚本 + 校验器
└── docs/            # 架构 / 内容规范 / 教学法文档
```

### 三层设计



* **知识层** `data/`：纯内容数据（JSON），朝代目录独立，字段有 Schema 约束

* **交互层** `web/`：纯原生 JS（ESM），零构建、零框架依赖

* **对话层** `plugin-final/`（可选）：DSH 插件，让 AI 以知识库为背景回答

> 网页本身
>
> **不依赖 DSH 即可独立运行**
>
> ，插件只是额外的对话入口。

## 📖 内容规范（重要）

内容面向学生与历史爱好者，遵守三条原则（详见 [docs/pedagogy.md](docs/pedagogy.md)）：



* **史实优先**：只讲有史料依据的内容；拿不准明说 "没有确切记载"；演义 / 传说必须标注 "小说演绎，正史不载"

* **通俗表达**：短句口语、专有名词首现时括号解释、数字换算成人能感的量

* **学习者当导演**：开放问题没有标准答案，先肯定思考再补充史实
