## 🧭 这个站想解决什么

学历史最常见的挫败是：年代表背了又忘，皇帝、思想家、诗人、工匠、神话各记各的，脑子里始终是一堆散点。

可在真实的历史里，它们从来不是散的——

**王安石在朝堂上推行变法时，程朱理学正在回应同一套时代困局；苏轼正走在贬谪的路上写下「大江东去」；《营造法式》的工匠们在汴梁城里起高楼；而宋人在志怪里安顿自己对未知的想象。**

这个站把**帝王、思想、诗人、工匠、神话**五条线并排摊开：你看到的不再是孤立的人名和年份，而是一个时代的因果与全貌。

- 想系统梳理朝代脉络的历史爱好者，能在这里立起时间坐标；
- 想入门传统文化的人，能沿着儒释道看清思想如何流变；
- 学生可以从「背年代」转向「理解因果」；
- 对科技史感兴趣的人，能从《考工记》一路读到《天工开物》《本草纲目》；
- 着迷于神话世界的人，能跟着《山海经》走到昆仑之丘、跟着唐僧走到雷音寺、跟着姜子牙走到牧野战场。

## 🚀 安装

### 只想看看，不装任何东西

直接打开在线演示：[https://zinging.github.io/chinese-history-atlas/web/](https://zinging.github.io/chinese-history-atlas/web/)

不需要 Node、不需要 clone、不需要配置。

### 完整站点 + AI 讲解员（推荐）

网页与讲解是**一体**的：AI 一边检索站内数据给出深链与配图，一边辅助你在右侧浏览器读懂画面——你看到的每个细节它都能接着讲。

**DSH 用户**（插件市场一键装）

在插件市场搜索 `@chenye123/chinese-history-atlas` 安装。装好后直接提问即可，例如「讲一下靖难之役」。插件会自动完成剩下的所有事：

- 检索站内数据作答（插件自带数据，装好即用）
- 首次使用自动从 Gitee 拉取完整站点（约 150MB，约 2 分钟，无需你执行任何命令）
- 自动在后台拉起本地网页服务，把可点击链接给你
- 讲解时自动配图，讲到谁就出谁的画像

**其他 MCP 客户端**（豆包 / Cursor / Claude Desktop 等）

先在本地起站点，再手动接入 MCP：

```bash
# 国内推荐 Gitee（快）；GitHub 镜像：https://github.com/zinging/chinese-history-atlas.git
git clone --depth 1 https://gitee.com/chen_ye_code/chinese-history-atlas.git
cd chinese-history-atlas
node web/serve.mjs          # 浏览器打开 http://127.0.0.1:5173/web/
```

然后项目根目录执行 `npm run mcp:install`（Windows；macOS/Linux 用 `bash web/tools/install-mcp.sh`），路径自动解析、配置 JSON 自动复制到剪贴板。Cursor / Zed 打开项目时直接识别根目录自带的 `.mcp.json`。

> 环境要求 **Node.js 18+**（自带 `fetch`，无需 `npm install`）。`--depth 1` 只取最新提交，下载约 150MB（图片占 141.5MB）；断网可用，图片全部本地读取。
> 端口被占用：`node web/serve.mjs 8080`。
> 请用本地服务器打开，**不要直接双击 HTML**：前端通过 `fetch` 读 `data/*.json`，`file://` 会被 CORS 拦截导致页面空白。

## 🗺️ 五大板块

### 🏮 一、帝王谱系 · 七朝权力的现场

`帝王世系` · `悬案疑案` · `舆图疆域` · `探案问史`

从隋到清，**7 朝 77 位皇帝**（隋 3 · 唐 14 · 五代 6 · 宋 18 · 元 8 · 明 16 · 清 12），一条横向卡片流贯穿一千三百年。点开任一皇帝，不是一段百科式简介，而是完整的「一生现场」：

- **帝王世系**：每位皇帝配**生平时间线（共 562 条）**、君臣后妃与对手关系、冷知识、争议话题，★ 标出重大转折；
- **悬案疑案**：**36 件**著名疑案（明 12 · 唐 5 · 宋 7 · 元 3 · 清 4 · 五代 3 · 隋 2），每件拆成八段——名称由来 → 时代背景 → 涉案人物 → 事件经过 → 结局 → 影响 → 开放讨论 → 史料出处，给你完整推理链而不是一句话结论；
- **舆图疆域**：可缩放地图叠加各朝疆域轮廓与古地名，**靖难南下、郑和下西洋、清军入关**等 **36 条行军航海路线**按时间轴分段动画；点任意古地名即对照今址（如「睦州」≈ 今浙江建德一带）；**141 个舆图事件**每个可弹出配图卡片与正文介绍；
- **探案问史**：**77 道史论选择题**（每帝一道），分「论证判断」（如何评价这项政策）与「因果链」（此事因何发生）两类，提交即批改；还有带出处线索的开放案卷，由你自己下判断。

### 📚 二、思想源流 · 中国人的底层操作系统

`典籍长廊` · `公案疑案` · `智慧舆图` · `探问问典`

**儒（孔孟）、道（老庄）、佛（禅宗）、诸子（兵法 / 法家 / 墨家）、理学心学（朱熹 / 王阳明）**，5 大流派、27 部核心经典，从先秦一路讲到明清。

- **典籍长廊**：27 部经典**63 篇名篇精读**，结合作者当时的处境读原文，而不是脱离时代死记——读《论语》看见周游列国的窘迫，读《韩非子》看见它如何被自己的逻辑反噬；原文与白话译文逐段对照；
- **公案疑案**：**15 件**思想悬案，如「孔子为什么诛杀少正卯」「庄子是真的逍遥还是失败者的自我安慰」，同样八段拆解；
- **智慧舆图**：**24 条圣贤行迹路线（82 个途经点）**落在地图上——孔子周游列国、玄奘西行取经、朱熹鹅湖之会到白鹿洞、王阳明龙场悟道到平定宁王……每个途经点都带**六层内容**：事发经过 → 史籍原句 → 白话译文 → 出处 → 历史意义 → 路线导语，看清思想如何在大地上流转、交锋、合流；另有 **51 处古今地名**与 **38 件百家纪事**（思想传播与学派形成的关键事件，含原文译文与四条意义），点事件在地图上标出地点并弹出配图卡片；
- **探问问典**：**13 道**侦探式追问，把带出处的线索摆给你，不给标准答案。

### 🎋 三、诗词鉴赏 · 先看处境，再读诗

`诗人长廊` · `诗坛公案` · `诗路舆图` · `品诗问典`

从屈原到纳兰性德，**22 位文人**排成一条长廊。这里不做机械背诵，而是**先看诗人一生走到了哪里，再读一首诗背后的处境、心情与公案**：

- **71 篇名篇精读**：每篇四层展开——原文、白话、写作背景、后世点评；专有名词随文注释；
- **95 条金句**：不做摘抄，每句配上人物心境与现实人生的解读。李白为什么在江陵写下「轻舟已过万重山」？因为他刚接到大赦令，劫后余生，船才显得那么快；
- **诗路舆图**：**13 条路线动态连线**，苏轼贬谪、李白漫游、杜甫流寓、岑参出塞……诗人去过哪里、在哪里写下名句，一图看尽；
- 另有 **107 条行迹年表、54 条冷知识、13 场诗坛公案、22 道品诗问典**（如李煜《虞美人》与牵机药之谜）。

### 🧭 四、格物致知 · 古人的科技与手艺

`格致典籍` · `工艺公案` · `器物图谱` · `格物问典`

**17 部古代科技典籍**分六大类铺开——工艺营造（考工记 / 营造法式 / 天工开物 / 梦溪笔谈）、医药本草（黄帝内经 / 伤寒杂病论 / 本草纲目 / 千金要方）、农书（齐民要术 / 农政全书）、算历（九章算术 / 周髀算经 / 授时历）、地理博物（水经注 / 徐霞客游记）、生活艺术（茶经 / 园冶）。

- **器物图谱**：**59 件**代表性器物，博物图谱式工笔白描插图，按书分组、点击可放大细看——后母戊鼎、错金银铜方案、斗拱、活字、水车……；
- **工艺公案**：**12 件**技术史悬案，追问「活字印刷为什么没能普及」「李时珍为什么要花 27 年重修本草」「《考工记》的六齐配比为什么是那个比例」；
- **格物问典**：**14 道**带史料线索的推理题，让你像技术史家一样判断；
- 每部典籍讲透「核心思想 + 章节介绍 + 历史境遇」，看清古代工艺如何一步步演进。

### 🐉 五、神话异志 · 按原著还原的想象力版图

`志怪典籍` · `神兽图鉴` · `神话舆图` · `探问异闻`

**9 部神魔经典**分四类——上古神话（山海经 / 搜神记）、神魔长篇（西游记 / 封神演义 / 镜花缘）、鬼狐笔记（聊斋志异 / 子不语 / 阅微草堂笔记）、小说总集（太平广记）。

- **志怪典籍**：每部书结合作者处境讲，原文与白话译文逐段对照，白话以棕字区分；
- **神兽图鉴**：**113 只神兽精怪**按书收录，统一工笔淡彩——从九尾狐、应龙、白泽、陆吾，到取经路上的各路妖魔；
- **神话舆图**：**5 张纯俯视工笔古舆图、69 个热点**，全部严格依原著文本的方位与地貌绘制，不是现代地图上贴标签：
  - **山海经・想象世界（22 站）**：招摇山、昆仑之丘、不周山、长留山、一目国、长臂国……神山异国该在哪个方位就在哪个方位；
  - **西游记・取经之路（17 难）**：高老庄、流沙河、火焰山、女儿国、小雷音寺、狮驼岭……沿西行次第展开；
  - **封神・战场（14 处）**：朝歌、牧野、昆仑山、汜水关、诛仙阵……还原商周大战的空间格局；
  - **聊斋・夜世界（8 场）**：兰若寺、太原王宅、崂山……跟着狐鬼故事的发生地走；
  - **太平广记・奇闻时空图（8 则）**：黄粱一梦、南柯太守、马嵬驿、普救寺……唐传奇的时空现场；
  - 每个热点都附**原文、白话译文与原著地貌描述**；
- **探问异闻**：8 道开放追问，把「神话为什么这样写」交给你判断。

## ✨ 这个项目有什么不同

**🗡️ 五条线并行，而不是五个孤立页面**

皇帝的决策、思想家的回应、诗人在流放路上的句子、工匠在工坊里的发明、先民想象中的神山神迹，本就是同一个文明的五个侧面。这里让你看见权力、思想、审美、工艺与想象如何彼此牵动。

**🗺️ 两套地图，各讲各的空间**

真实历史用 Leaflet 地图：疆域轮廓、古地名今址、行军航海路线按时间轴回放；神话世界则抛弃现代地图，改用**按原著逐点校对的俯视工笔古舆图**——长臂国在东、交胫国在东，火焰山、昆仑山、女儿国该在哪就在哪，想象的归想象，绝不拿现代地图冒充山海经。

| 舆图疆域：路线按时间轴回放 | 悬案疑案：八段式完整推理链 |
| :---: | :---: |
| ![舆图疆域](docs/demo/map.gif) | ![悬案疑案](docs/demo/cases.gif) |
| **探案问史：带出处的线索交给你判断** | **帝王世系：时间线与关系图** |
| ![探案问史](docs/demo/detective.gif) | ![帝王世系](docs/demo/timeline.gif) |

**📂 案件式深读，而不是百科式罗列**

全站 **76 件案件档案**（帝王 36 + 思想 15 + 诗词 13 + 格物 12），全部按「名称由来 → 背景 → 人物 → 经过 → 结果 → 影响 → 开放讨论 → 史料出处」八段组织。给你的是完整推理过程，而不是「某某年发生某事」的一句话。

**🕵️ 侦探式问典，而不是背题**

全站 **57 道问典题**（思想 13 + 诗词 22 + 格物 14 + 神话 8），像侦探游戏一样：先抛出案子，再逐条给出**标注了出处的线索**，最后留出没有标准答案的思辨题和作答区——另有帝王谱系 **77 道史论选择题**（论证判断 + 因果链两类），提交即批改。

**📖 原文与白话对照，而不是只给结论**

经典、诗词、舆图热点都保留原文原话，紧跟一段白话译文（棕字区分）；圣贤行迹的每个途经点也是六层展开——事发经过 → 史籍原句 → 译文 → 出处 → 历史意义 → 路线导语。既读到古人的原话，又能立刻读懂它在思想史上意味着什么。

**🔍 演义与正史分开，线索可溯源**

时间线与侦探线索均标注《旧唐书》《宋史》《明史》等出处；演义传说单独标注「小说演绎，正史不载」；神话内容严格忠于原著文本——不让你把《三国演义》当正史读，也不让想象图冒充山海经原文。

**🖼️ 近千张工笔插图，是统一画风，不是模板皮肤**

全站统一宣纸米黄、朱红印章、工笔淡彩视觉：113 只神兽、59 件器物、163 张帝王与人物像、5 张古舆图、141 张舆图事件工笔彩绘、38 张百家纪事配图，合计 **981 张**全部为同一画风手绘生成；古地图按原著方位与地形特征逐点校对。

**⚡ 零依赖、秒打开，离线也能用**

纯原生 HTML / CSS / JS，无构建、无框架、无后端，`data/` 全是可读可改的 JSON，无需 `npm install`、无需数据库；地图库与字体全部本地化，断网照常运行。七个朝代的数据**并发加载**，「全部」视图下 136 个 JSON 只需一个往返就就绪；JSON 按板块分片、切到才拉；图鉴和舆图卡片走缩略图，缺失自动回退。

**🤖 AI 讲解员开箱即用，图文并茂**

内置零依赖 MCP Server（v1.6.0，15 个只读工具），豆包 / Hermes / Cursor / Claude Desktop 等客户端一行配置接入：AI 只读站内数据、不联网，回答带深链直达页面、带**配图内容块**——讲到朱元璋就出朱元璋的画像，讲到九尾狐就出九尾狐的工笔彩绘，讲到靖难之役就出事件工笔图。倒排索引毫秒级检索，单对象结果自动附带 base64 图片块，列表类结果不附图（需要时用详情接口取单条）。另有网页内 OpenAI 兼容接口（DeepSeek / OpenAI 等），配置仅存于本机 `web/llm-config.json`（已 gitignore），问答内容不上传任何服务器。

## 🤖 AI 讲解员怎么工作

项目内置一个**零依赖 MCP Server**（`web/tools/history-mcp-server.mjs`，15 个只读工具）。它只检索站内数据、不联网，把「页面呈现」与「讲解」绑在一起——给出深链让右侧浏览器打开对应位置，同时把配图直接推进对话。

- **自动拉起服务**：MCP 自己探活，未运行就在后台启动站点（脱离 MCP 独立存活，约 0.8 秒就绪），AI 直接给出可点击地址——不搜硬盘、不拼路径
- **自动拉取站点**：新用户首次提问，MCP 自己从 Gitee 拉取完整项目到主目录（约 150MB，约 2 分钟），无需用户执行任何命令；拉取完自动启动服务
- **图文并茂**：单对象结果（皇帝 / 典籍 / 器物 / 事件）自动附带 base64 图片内容块，讲到谁就出谁的画像；列表类结果不附图（几十张会撑爆返回体），需要时用详情接口取单条
- **毫秒级检索**：内置单字/双字倒排索引（897 篇文档），首次建索引约 230ms，之后每次检索 1–2ms；「土木堡之变」「兰若寺」「高老庄」「昆仑之丘」「鹅湖之会」等直达对应地图事件或舆图热点
- 完整配置说明见 [`docs/AI集成-本地MCP配置.md`](docs/AI集成-本地MCP配置.md)；自检 `npm run mcp:selftest`

## 📖 内容规范

- **史实优先**：只讲有史料依据的内容；存疑处明说「没有确切记载」；演义传说标注「小说演绎，正史不载」。
- **原著优先**：经典、诗词、神话保留原文，紧跟白话译文；神话舆图与热点严格忠于原著文本。
- **通俗表达**：短句口语，专有名词首现时括号解释（如「幽云十六州（今北京、天津及山西、河北北部一带）」）。
- **学习者为主导**：开放问题不设标准答案，先留思考空间再补史实；选择题正确项打散位置，避免靠位置猜答。
- **中立立场**：不站队、不美化，争议话题呈现多方观点后交由学习者自行判断。
